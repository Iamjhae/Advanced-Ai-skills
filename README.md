# Web Security & Bug Hunting Methodology

A categorized collection of web application security testing methodologies, attack vectors, payloads, and notes compiled during security assessments and bug bounty research.

## Repository Structure

- **API Security**: Authentication bypass, BOLA/IDOR, rate limiting, and mass assignment vectors.
- **Authentication & Session**: OAuth flaws, JWT vulnerabilities, session fixation, and token leakage.
- **Broken Access Control**: Privilege escalation (horizontal & vertical), IDOR, and path traversal.
- **Business Logic**: Price manipulation, race conditions, and workflow bypasses.
- **HTTP Web Infrastructure**: Web cache poisoning/deception, request smuggling, and proxy behavior.
- **Injection**: SQLi, Command Injection, XSS, and template injection payloads.
- **Integrations**: Third-party API security and webhook testing.
- **Match & Replace**: Custom Burp Suite rules and Regex filters for security workflows.
- **Report**: Vulnerability reporting templates and proof-of-concept (PoC) structure.
- **Server-Side Request & File Handling**: SSRF, LFI/RFI, and insecure file upload mechanics.
- **SSRF**: Server-Side Request Forgery escalation pathways and cloud metadata extraction.
- **Web Bug Hunting**: General methodology, reconnaissance workflows, and checklist notes.

## Usage
This repository serves as a personal reference for penetration testing engagements, CTF challenges, and bug bounty hunting.
